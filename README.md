# 쎄깐제과 화면 재현 연습

첨부된 메인/전체상품 화면의 구성과 색감을 참고해 새로 만든 정적 웹사이트입니다. 실제 쇼핑몰, 주문, 문의, 로그인 기능은 없습니다.

## 실행 및 GitHub Pages 배포

`index.html`을 브라우저로 열면 메인 화면이 표시됩니다. 메인의 `전체상품`을 누르면 `products.html`로 이동하고, 전체상품 화면의 로고를 누르면 메인으로 돌아옵니다.

GitHub 저장소에 이 폴더의 파일을 업로드한 다음, 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, `main`, `/ (root)`를 선택하면 됩니다. 모든 내부 경로는 상대 경로입니다. 이번 작업에서는 업로드나 공개 배포를 진행하지 않았습니다.

## 이미지와 문구

- `assets/hero-heart.png`, `hero-macaron.png`, `dessert-banner.png`, `macaron-grid.png`, `dessert-grid.png`, `shell-dacquoise-grid.png`: OpenAI image_gen으로 이 프로젝트를 위해 새로 생성한 이미지. 원본 사이트의 사진 파일은 사용하지 않았습니다.
- 생성 이미지 출처: OpenAI image_gen. 외부 스톡 이미지나 제삼자 이미지 라이선스는 사용하지 않았습니다. 공개 이용 조건은 배포 전 OpenAI 서비스 약관과 참고 화면의 디자인 사용 허락 범위를 확인해 주세요.
- 메인 배너 이미지 3장은 각각 하트카롱, 마카롱, 디저트 구성의 새 이미지입니다. 화면 자료의 실제 이미지·크롭과는 차이가 있습니다.
- 전체상품의 제품 카드 이미지는 생성한 3×3 이미지 그리드를 분할 표시합니다. 실제 품목별 원본 사진과 일치하지 않을 수 있습니다.
- 전체상품 상단 분류는 제공된 메뉴 화면의 여섯 종류로 구성했습니다. 개별 맛 이름은 자료로 확인되지 않아 카드에서 표시하지 않았습니다.
- 외부 폰트, 아이콘, 영상은 사용하지 않았습니다. 기본 Arial/맑은 고딕 계열 글꼴과 CSS 도형을 사용했습니다.
- 상세 후기, 상품명, 설명, 사업자 정보는 원문의 게시 허가가 확인되지 않아 대체 문구 또는 생략으로 처리했습니다. 숫자와 제품 설명도 연습용 화면 표현이며 실제 정보로 사용하면 안 됩니다.

## 화면 자료로 확인하지 못한 부분

제공된 긴 화면 캡처는 축소되어 있어 일부 작은 문구, 개별 상품 사진, 모바일 전용 배치, 실제 메뉴창 모습, 원본 배너의 전환 주기와 효과를 정확히 확인할 수 없었습니다. 모바일은 데스크톱 화면의 구성을 바탕으로 반응형으로 구현했습니다. 원본 이미지와 모바일 캡처가 제공되면 배치와 크롭을 더 정확히 맞출 수 있습니다.

## 사용한 이미지 생성 프롬프트 요약

1. 파스텔 분홍 배경과 하트 마카롱을 배치한 가로형 스튜디오 사진, 오른쪽 제목 여백.
2. 민트 배경의 다색 마카롱과 흰 받침대를 배치한 가로형 스튜디오 사진, 오른쪽 제목 여백.
3. 마카롱·하트카롱·다쿠아즈·쿠키를 아이보리 배경에 배치한 가로형 스튜디오 사진.
4. 9가지 둥근 마카롱을 3×3 격자로 배치한 카드용 제품 사진.
5. 하트카롱·뚱카롱·다쿠아즈·쿠키를 3×3 격자로 배치한 카드용 제품 사진.
6. 포장된 꼬끄와 다쿠아즈를 3×3 격자로 배치한 카드용 제품 사진.

모든 이미지 프롬프트에서 글자, 로고, 워터마크를 제외하도록 요청했습니다.
